# Taiwan rail package 2025 — official rebuild

`tw-2025.json` is rebuilt from official Taiwan government/open-operator data.
It uses the same `compact-v1` schema as `jp-2025.json` and contains 38
passenger railway, metro, and light-rail display lines.

The 2025 package name is retained for compatibility with the app's country
package selector. Version `2025.4.0` is a clean official-data rebuild; it does
not inherit station order, station grouping, or geometry from an older Taiwan
package.

## Data authorities

- Ministry of Transportation TDX/PTX rail APIs
  - Official Shape, Station, and StationOfLine responses for Taiwan High Speed
    Rail, Taiwan Railways, Taipei Metro, New Taipei Metro, Taoyuan Airport MRT,
    Taichung Metro, Kaohsiung Metro, Danhai LRT, Ankeng LRT, and Kaohsiung LRT.
  - API documentation: <https://tdx.transportdata.tw/api-service/swagger/basic/5fa88b0c-120b-43f1-b188-c379ddb2593d>
- Ministry of the Interior, National Land Surveying and Mapping Center (NLSC)
  - Railway centerlines: <https://data.gov.tw/dataset/73220>
  - Railway stations: <https://data.gov.tw/dataset/73226>
  - Metro centerlines: <https://data.gov.tw/dataset/73222>
  - Light-rail centerlines: <https://data.gov.tw/dataset/73229>
  - Light-rail stations: <https://data.gov.tw/dataset/73230>
- Ministry of Agriculture, Alishan Forest Railway and Cultural Heritage Office
  - Detailed Alishan/ Zhushan SHP: <https://data.gov.tw/dataset/38129>
  - Official station sequence and mileage: <https://afrch.forest.gov.tw/>
- Taipei City Department of Rapid Transit Systems
  - Taipei metropolitan MRT network GIS JSON:
    <https://data.taipei/dataset/detail?id=afccd2ac-75b1-4362-9099-45983e332776>

All sources above are public official data. Their applicable license is the
Government Open Data License, version 1, or the publishing authority's stated
open-data terms.

## Geometry method

TDX/PTX supplies official station membership, station order, names, English
names, coordinates, and WGS84 route Shapes. NLSC centerlines are combined with
the matching TDX Shapes to resolve official-record topology breaks and retain
detailed station-area geometry. The source graph is strictly isolated by the
official `LineID`, `RAILNAME`, `MRTCODE`, or `LRTCODE`; unrelated tracks are
never placed in a line's routing graph. Taipei City's detailed MRT GIS is
preferred for the matching Taipei line curves. The Ministry of Agriculture
detailed SHP closes the NLSC Zhushan topology gap; the NLSC layer supplies the
Alishan approach.

Each logical display line is built from a blank data structure. The generator:

1. selects the official ordered station list;
2. identifies an official connected component covering every station;
3. uses a dynamic program over official platform/track candidates so adjacent
   station intervals share the same official graph node;
4. routes every interval through official graph edges;
5. rejects disconnected paths, implausible shortcuts/detours, and any
   synthetic connector;
6. subdivides a sparse official tunnel/viaduct edge at 200 m without changing
   the published alignment, so no compact segment is a two-coordinate chord;
7. compares every generated vertex and every edge midpoint with that line's
   scoped official source geometry and fails above a 20 m tolerance.

The output audit requires 38 lines, continuous adjacent segments, zero
two-point segments, zero synthetic connectors, and no output coordinate edge
of 500 m or longer. The package records the comparison result for each line in
`geometrySource.officialGeometryComparison.byLine`. OpenStreetMap input and
fallback count are both zero.

## Rebuild

Download fresh official snapshots to a temporary directory:

```sh
cd app
python3 scripts/download-taiwan-rail-official.py \
  --output-dir /private/tmp/tw-rail-official
```

Then perform the clean build:

```sh
python3 scripts/build-taiwan-rail-package.py \
  --source-dir /private/tmp/tw-rail-official \
  --alishan-detail /private/tmp/tw-rail-official/alishan_official_11001.zip \
  --alishan-rail /private/tmp/tw-rail-official/tw_rail_open.zip \
  --alishan-stations /private/tmp/tw-rail-official/tw_rail_station_open.zip \
  --nlsc-mrt /private/tmp/tw-rail-official/tw_mrt_open.zip \
  --nlsc-lrt /private/tmp/tw-rail-official/tw_lrt_open.zip \
  --nlsc-lrt-stations /private/tmp/tw-rail-official/tw_lrt_station_open.zip \
  --taipei-metro /private/tmp/tw-rail-official/taipei_metro_official.json
```

The generated package records a SHA-256 fingerprint for every downloaded
input. The large source snapshots are not committed. The deterministic gzip
sidecar is generated locally for the server/static build workflow.
